PFO 2 - Sistema de Gestión de Tareas

API REST desarrollada con Flask, autenticación y base de datos SQLite

Descripción del proyecto

Este proyecto consiste en el desarrollo de un sistema básico de gestión de tareas mediante una API REST. El sistema permite registrar usuarios, iniciar sesión y acceder a un recurso protegido mediante autenticación.

Tecnologías utilizadas

  • Python
  • Flask
  • SQLite
  • Werkzeug para el hash de contraseñas
  • Thunder Client para las pruebas de la API

Endpoints principales

POST /registro
Permite registrar un nuevo usuario.
POST /login
Verifica las credenciales e inicia la sesión.
GET /tareas
Permite acceder al sistema únicamente después de iniciar sesión.

Seguridad

Las contraseñas no se almacenan en texto plano. Se utiliza una función de hash proporcionada por Werkzeug para proteger las credenciales almacenadas en la base de datos.
